Веб-приложение для просмотра Swagger/OpenAPI спецификаций и визуализации структур SQL баз данных с возможностью сохранения избранных схем.

##  Функциональность

### Swagger визуализатор
-  Загрузка схемы по URL (например, https://petstore.swagger.io/v2/swagger.json)
-  Загрузка из JSON файла
- ️ Ручной ввод JSON кода
-  Валидация JSON с выводом ошибок
-  Отображение:
    - Общей информации об API (название, описание, версия)
    - Эндпоинтов с HTTP-методами (GET, POST, PUT, DELETE)
    - Параметров запроса (таблица: имя, тип, обязательность)
    - Ответов с кодами HTTP и JSON-схемой
    - Схем данных (definitions)
-  Копирование JSON ответов в буфер обмена

### SQL визуализатор
- Загрузка SQL файла с CREATE TABLE выражениями
- Парсинг:
    - Названий таблиц
    - Полей и их типов данных
    - Первичных ключей (PRIMARY KEY)
    - Внешних ключей (FOREIGN KEY)
- Автоматическое определение связей по полям *_id
- Визуализация:
    - Карточек таблиц со списком полей (PK, FK маркеры)
    - Интерактивного графа связей с помощью ECharts

### Избранное
-  Сохранение схем в личное избранное
- ️ Удаление схем из избранного
-  Автоматическое сохранение после перезагрузки (бэкенд)

### Интерфейс
-  Переключение между светлой и темной темой
-  Адаптивный дизайн (мобильные устройства и десктопы)
-  SEO оптимизация (мета-теги, Open Graph)

## 🚀 Установка и запуск

### Требования
- Node.js 18+
- Python 3.9+
- npm или yarn


### Запуск бэкенда (FastApi)
cd back
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate     # Windows

pip install fastapi uvicorn python-multipart
uvicorn main:app --reload --port 8000


### Запуск фронтенда(Next.js)
cd front
npm install
npm run dev
